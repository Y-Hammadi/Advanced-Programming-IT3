## Task 1: Add a New Page to the MVC Application

**Task:** Create a new page of your own choice in the `FirstMvcApp` project, following the same approach used to create the `About` page during the lecture.

### Requirements
1. Choose a page name and purpose of your choice.
2. Add a new Action to `HomeController`.
3. Create the corresponding View inside `Views/Home`.
4. Add a link to the new page in the navigation bar (`_Layout.cshtml`).
5. Make sure the page works correctly when you run the application.

### Examples
You may choose one of the following pages or suggest your own:

- **Contact:** A page containing contact information.
- **Services:** A page describing the services provided by the application.
- **Help:** A page containing basic help information.
- **Profile:** A simple user profile page.

### Submission
Be ready to demonstrate your new page and explain how its URL is connected to the Controller Action and View.
